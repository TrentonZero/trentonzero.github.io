Everything else under publish/jekyll/ is generated by scripts/split_mockup.py in the health-stats repo; this file is not, because it is the only part that is Liquid. It is deliberately thin. All the markup lives in _includes/journey-body.html, which contains no Liquid at all, so the browser tests in health-stats can load the real include rather than an approximation of it. The untested surface is therefore just the twenty-odd lines below -- short enough to read. THE TWO JSON BLOCKS #journey-data is data/journey.json, copied into _data/ unchanged. scripts/build_journey.py is the disclosure boundary: nothing reaches this page that it did not explicitly assemble. If a new field is wanted, add it there. #journey-posts is generated here, from site.posts, because `posts` has no source in the private repo and never should have one -- Jekyll is the only thing that knows this blog's permalink scheme, its current titles, and which posts are published. Drafts (published: false) never appear in site.posts, so they cannot leak. This is what replaced scripts/splice_mockup.py. `sort: "date"` matters: site.posts is newest-first and the chart's gutter stacking walks the array in order. `journey_say` is optional post front matter -- a one-line caption shown in the readout when that post is selected. Absent, the readout just shows the title. CAVEAT: jsonify does not escape ``. No current title or caption contains it. If one ever does, this page will break in an obvious way rather than a subtle one, but it is worth knowing why. {% endcomment %} {% include journey-body.html %}
